# macos: correction to the coverage-accounting entry

## Summary

Corrects one line of the 07:17 entry, which said inventory is re-collected
"after a scan that could clear prior findings". Since the reconciliation work
it re-reads inventory after every successful online scan, whatever the
retention consequences. Entries are append-only, so this correction is the
record.

## Changes

- No code change in this entry beyond what the same review round produced:
  ambiguous keg versions (a keg whose literal name is also another keg's base,
  e.g. `1_2` beside `1_2_1`) are excluded from the version index and keep their
  findings as unknown instead of inheriting another version's advisory;
  `HOMEBREW_NO_INSTALL_CLEANUP` is now unset via `env -u` on approved upgrades,
  because an exported variable would otherwise be inherited; `brew outdated`
  requires both collections to be present; an empty advisory summary or a
  multiline one no longer discards the scan.
