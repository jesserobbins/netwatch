# approval artifacts default to the database directory

## Summary

One inconsistency the audit named and I had only half-fixed: `cleanup()` looked in the
database's directory while `preview()` defaulted to the global state directory, so a run
with `--db /tmp/x.db` wrote approval artifacts cleanup would never find.

## Changes

- `preview(..., state_dir=None)` now defaults to `Path(store.db_path).parent`, the same
  directory `cleanup()` scans, so artifacts and the cleaner agree wherever `--db` points.
- A test drives the default path (no `state_dir` argument) and asserts cleanup removes the
  file preview wrote.

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 377 tests, OK.
- `tests/test_audit_fixes.py DefaultStateDirTests.test_preview_defaults_to_the_databases_directory`
  covers the default; `CleanupWithCustomDatabaseTests` covers the explicit path.
