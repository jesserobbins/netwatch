# held distributions reach the plan body so the gate can check them

## Summary

While checking my own condition-(5) fix I found it was dead: the gate read `body["held"]`, but
the plan body never carried it, so a held distribution that disappeared could never fail the
gate.

## Changes

- `preview` writes `held` (the direct/VCS/local distributions it pinned at their current
  version) into the plan body.
- The post-install gate compares that list against the installed set and reports
  `needs_attention` when one is gone, which is what "the pin should have held it" means.

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 391 tests, OK.
- `tests/test_audit_fixes.py HeldDistributionTests.test_a_held_distribution_that_disappears_needs_attention`
  registers a VCS-origin tool, offers it a candidate, and asserts preview holds it rather than
  planning an index upgrade.
