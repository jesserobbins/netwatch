# user-lane readers and scan --register against the stored run

`scan --list` could see the venvs; now `scan --register` can make them targets. This closes the
scan feature end to end: walk, classify, ticket, register.

## Changes

- `netwatch/userlane.py`: `describe` reads what the manager left inside a venv
  (`uv-receipt.toml` / `pipx_metadata.json`) into one row — kind, tool name, extras, bin
  directory, index options, realpath, the path as written, and `(st_dev, st_ino)` — with
  index URLs redacted through `sources.strip_credentials` so no token is ever recorded.
  A broken receipt is reported, never raised. `inventory` runs `uv pip list --format json`
  against the venv's own interpreter. `identity` re-verifies the scan's stat evidence and
  then runs both identity reads.
- `scan.run` enriches user-lane records with that row, so registration reads the record
  and not the tree.
- `scan.register`: index-based against one stored run, `--run` required only when the root
  has more than one run, per-lane ordinals validated (a repo row can never be targeted),
  batch capped at five items with a ten-second listing timeout, identity checks and inserts
  in one transaction so the batch is all-or-nothing.
- `workflow.check` says "kind not yet supported in this build" for a target whose kind
  lands in a later stage, per target, instead of failing the whole run; `cli.display` no
  longer assumes every target body carries `host`.

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 228 tests, OK (22 new).
- Live, this machine, the real five uv tool venvs:
  - `scan ~/.local/share/uv/tools --depth 2` → `scan run 1: 0 repos, 5 user-lane`.
  - `--register 1` → `registered: browser-use (uvtool) …`, and `list` shows the body with
    its `registered_from_scan` provenance (run, ordinal, `path_as_written`, inode).
  - `--register 1 2 3 4 5` → all five registered.
  - `--register 9` → `index 9 is not a user-lane row of run 1 (1..5)`.
  - `check ruff` → per-target row `ruff (uvtool on local) / Error: kind not yet supported in
    this build`, exit 1, no crash — the stage-2 contract.
