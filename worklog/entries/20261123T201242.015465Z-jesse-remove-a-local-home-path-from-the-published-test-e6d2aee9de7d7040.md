# remove a local home path from the published test fixtures

## Summary

Two test fixtures carried `/Users/jesse/.local/bin/...` in their `install-path` values. This
repository is published, so that is a leak of the local home layout into a public artifact — the
green-room rule about never publishing paths, caught while checking exactly that.

## Changes

- `tests/fixtures/uv-receipt.toml` and `tests/fixtures/uv-receipt-extras.toml` now name
  `/home/example/.local/bin/...`.
- The fixtures stay format-faithful — uv's receipt shape is what they pin — but they no longer
  describe this machine. Tests that need the real path rewrite it themselves.

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 432 tests, OK.
- `git grep -e "netwatch-private" -e "/Users/jesse"` over tracked files — no matches.
