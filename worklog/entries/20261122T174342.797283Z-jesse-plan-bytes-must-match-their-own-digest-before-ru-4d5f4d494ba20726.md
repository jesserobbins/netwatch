# plan bytes must match their own digest before running

## Summary

Step (5) now runs the verified copy of the plan's bytes, which made one more hole visible:
nothing checked that those bytes still matched the digest the plan recorded for them.

## Changes

- `apply` verifies `digest(body["constraints"]["bytes"])` against
  `body["constraints"]["digest"]` before writing the temp copy, and refuses if they differ.
  What runs is then proven to be what the approval recorded, not merely what the file on
  disk said at step (4).

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 382 tests, OK.
- `tests/test_audit_fixes.py PlanByteIntegrityTests.test_tampered_plan_bytes_are_refused`
  rewrites the plan's stored bytes and asserts apply refuses with the digest reason.
