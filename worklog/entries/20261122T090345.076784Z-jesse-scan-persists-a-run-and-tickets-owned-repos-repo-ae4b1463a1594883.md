# scan persists a run and tickets owned repos; report writes anywhere

## Summary

`scan` is now the command the design describes: it walks a root, tickets the repos netwatch
owns, persists the run so `--register` can index into it, and tells the operator what it
skipped and why. `report <path>` is the explicit escape hatch for any repo.

## Changes

- `scan.owner_of`/`scan.owned`: ownership is a github.com remote whose owner is in the
  handle set; `handles_from` adds the authenticated `gh api user` login (one read-only
  call) to any `--handle` names, and a missing or failing `gh` degrades to the explicit
  names instead of failing the scan.
- `scan.run` persists `scan_runs` plus one `scan_records` row per lane item with per-lane
  1-based ordinals, writes tickets only into owned repos, records a `ticket_written`
  event, and returns the summary line with the run id.
- `scan.report` writes a ticket into any repo on request.
- `Store.scan_run`, `Store.scan_record`, `Store.scan_run_row`, `Store.scan_records`.
- `tickets.collect` and `scan.run`/`scan.report` take an optional one-hour OSV cache
  (`Store.cached`), which turns a repeat scan from minutes into under a second.

## Validation

- `.venv/bin/python -m unittest discover -s tests -q` — 206 tests, OK (12 new).
- Live, this machine, real git and real `gh`:
  - synthetic root with one `jesserobbins` remote and one `lhl` remote → `scan run 1: 2
    repos, 0 user-lane, 0 unclassified`, ticket written into the owned repo only,
    `skipped: … (not an owned repo)` for the other, and `report` then wrote into the
    foreign repo on request.
  - `scan ~/GitHub --depth 1` → 25 repos: **2m35s cold** (git reads plus one OSV query per
    package), **0.69s warm** with the cache. `--list --depth 2` on the same root: 0.099s.
- **Side effect, corrected:** that live scan ran against the real `~/GitHub`, so it wrote
  eleven `.netwatch` files into real working trees. Each was untracked and
  netwatch-generated (verified), they were removed, and one was kept at
  `/tmp/sample-real-ticket.netwatch` as evidence. Live scans belong on synthetic roots.
